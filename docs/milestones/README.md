# Milestone Documents

This folder holds one **deep-dive learning document per milestone**. Because
Dungeon Agents is an educational project, each document explains not just *what*
was built but *why* — the design decisions, the concepts you're meant to learn,
the QA-mindset angle, and what carries over to the future **TestOps AI** product.

Read them in order. Each one assumes you've read the previous.

## Document shape

Every milestone doc follows the same structure so they're easy to compare:

1. **Goal** — what this milestone is for, in one paragraph.
2. **What was built** — point by point, each with a *why it matters*.
3. **Concepts learned** — the transferable ideas.
4. **QA mindset** — testability, observability, reproducibility, safe failure.
5. **How to test / verify it** — commands and expected results.
6. **Risks & tradeoffs** — what we deferred and why.
7. **Bridge to TestOps AI** — what carries over.
8. **What's next** — the following milestone.
